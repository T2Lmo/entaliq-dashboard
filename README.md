# مكتب انطلق الذكي — لوحة المؤشرات

واجهة ثابتة تُنشر على GitHub Pages وتتصل بخادم Google Apps Script (`Code.gs`).
لا تحتاج خطوة بناء: الملفات تُخدَم كما هي.

## البنية

```
index.html          الهيكل (HTML فقط)
css/styles.css      كل التنسيقات
js/                 سكربتات عادية (ليست modules) تتشارك النطاق العام، وتُحمَّل بهذا الترتيب:
  config.js         الوكلاء والفترات ومفاتيح التخزين والحالة والأيقونات
  api.js            الاتصال بخادم Apps Script (POST + ACCESS_TOKEN)
  utils.js          أدوات الحساب والعرض والمؤشرات
  dashboard.js      العدّاد والبطاقات والبلاطات وفلتر الفترة وتطور الأداء والشريط
  views.js          اللوحة الجانبية: المهام والأخبار والبحث والفريق والتنبيهات
  content.js        المحتوى والاعتماد
  designs.js        رسم تصاميم المنشورات بهوية كل علامة وإجراءات المحتوى
  app.js            الرسم الكامل والتحديث والإجراءات والإعدادات
  office.js         إدارة المكتب: الوكلاء والدوام والمهام المجدولة والأتمتة وتعديل التصاميم، وأدوات كل وكيل تحت اسمه وسجل المكتب وإعدادات ملخص الصباح وتنبيه توقف العامل
  executive.js      ملخص راكان التنفيذي: ما أنجزه كل وكيل ونتائجه ومقترحات التكليف
  brain.js          عقل المكتب ومرجعه: الدروس والأمثلة، «علّم الوكيل» من سجل المهام، وحفظ ملاحظاتك على المنشورات
  studio.js         استوديو المحتوى: «أكمل المنشورات الآن» (الوكلاء يكتبون ويصممون، وأنت تعتمد أو ترفض)
  prospects.js      مازن: منشآت سعودية ببريدها الرسمي ومسودات رسائل ترسلها أنت
  tenders.js        بدر: المنافسات والمناقصات والترسيات ولوحة الجاهزية
  contracts.js      عقود صيانة الطاقة الشمسية: الباقات والأسعار، عرض السعر والعقد للطباعة، الزيارات والتجديد
  audits.js         عروض تدقيق الطاقة لسلطان: باقات ASHRAE بأسعارك لكل م²، معاينة القيمة، العرض المطبوع، والسجل حتى تسليم التقرير
  voice.js          راكان بالصوت: الميكروفون والنطق في المتصفح، والمحادثة، والتأكيد، وتشغيل المهام والتكليف بالصوت وقراءة نتيجتها، والموافقات بنداً بنداً
  health.js         صحة المكتب: فحص الخادم والعامل والبريد والمشغلات والوكلاء، مع طريقة إصلاح كل خلل ونقطة تنبيه على زر إدارة المكتب
  pipeline.js       مسار المبيعات: الصفقات ومراحلها وقيمتها وخطوتها القادمة، والمتوقع وربح الشهر، وتنضاف وحدها من مازن وبدر وعروض الصيانة ونموذج الموقع، وتبويب «من الموقع»
  lead.js           نموذج «اطلب تواصلاً» (lead.html وcss/lead.css) لموقعي انطلق ووهج: يرسل الطلب إلى الخادم فقط، بحماية من الإزعاج
  auth.js           الدخول بحساب Google
  social.js         ربط LinkedIn و X والنشر المباشر
  events.js         ربط الأحداث
  main.js           البداية (يُشغَّل أخيراً)
apps-script/        ملفات تُضاف إلى مشروع Apps Script (Auth.gs, Social.gs, ClaudeBridge.gs, Office.gs, Executive.gs, Brain.gs, Studio.gs, Prospects.gs, Tenders.gs, Contracts.gs, Digest.gs, Voice.gs, Health.gs, Pipeline.gs, Leads.gs, Audits.gs, Sites.gs) وخطوات التفعيل في SETUP.md
worker/             عامل على جهازك: ينفذ طلبات الوكلاء بـ Claude باشتراكك (بدون API)، ويرسل رسائل مازن المعتمدة من بريد الشركة ويقرأ ردودها (start-worker.cmd يعيد تشغيله إن توقف، وinstall-autostart.cmd يشغّله مع Windows)
tools/              deploy-server.mjs: تحديث الخادم بأمر واحد (deploy-server.cmd في جذر المستودع) عبر clasp، بنسخة احتياطية وتحقق من النسخة
```

> عند كل تحديث للخادم: زد `HEALTH_.server` في `apps-script/Health.gs` و`SERVER_VERSION` في `js/config.js` بالرقم نفسه، لتنبهك «صحة المكتب» إن بقي كود قديم منشوراً.

> الترتيب في `index.html` مهم: كل ملف يستخدم ما عُرّف في الملفات التي قبله عند التحميل.

## التشغيل محلياً

```
npx http-server -c-1 .
```

ثم افتح `http://localhost:8080` وأدخل رابط `/exec` ورمز `ACCESS_TOKEN` من الإعدادات.

## الخادم (Google Apps Script)

كود الخادم غير موجود في هذا المستودع بعد. لتنزيله إلى مجلد `apps-script/`:

```
npm install -g @google/clasp
clasp login
mkdir apps-script && cd apps-script
clasp clone <SCRIPT_ID>
```

`SCRIPT_ID` من محرر Apps Script ← إعدادات المشروع (Project Settings) ← Script ID.
لا ترفع `.clasprc.json` ولا قيم Script Properties (مثل `ACCESS_TOKEN` ومفتاح النموذج) إلى GitHub.
